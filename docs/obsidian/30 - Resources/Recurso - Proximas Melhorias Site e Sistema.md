# Recurso - Proximas Melhorias Site e Sistema

Fonte principal: `docs/strategy/next-improvements-report.md`

## Leitura rapida

O projeto ja tem base boa o bastante para sair da fase conceitual.
O foco agora deve ser ativacao real e rotina operacional.

## Prioridades imediatas

1. configurar canais reais da home
2. conectar Supabase real
3. validar o fluxo `lead -> diagnostico -> conta -> projeto`
4. reforcar prova comercial no site
5. evoluir CRM com filtros, busca e deals

## Regra de decisao

Sempre priorizar:

- conversao
- rotina comercial
- memoria operacional
- padronizacao

Antes de priorizar:

- sofisticacao
- automacao profunda
- features bonitas sem impacto de negocio
