# Mekka Labs — Obsidian Vault

Este vault e o segundo cerebro do relancamento da Mekka Labs.

## Como abrir

1. Instale o Obsidian
2. Escolha `Open folder as vault`
3. Selecione `docs/obsidian/`
4. Abra `[[Home]]`

## Estrutura

- `00 - Inbox` captura rapida
- `10 - Projects` iniciativas com prazo e dono
- `20 - Areas` responsabilidades continuas
- `30 - Resources` referencias, runbooks e proposta de valor
- `40 - Archive` historico
- `50 - MOCs` mapas de conteudo
- `60 - Daily` diario de execucao
- `70 - Templates` templates
- `80 - Attachments` anexos

## Uso recomendado

- registrar decisoes de oferta, posicionamento e operacao
- documentar runbooks de entrega
- manter backlog comercial visivel
- transformar aprendizados em processo
